# Διαιτολογικό γραφείο

Εργαλείο για πλάνα διατροφής. Στατική σελίδα (GitHub Pages) με σύνδεση και αποθήκευση στο Supabase (Φρανκφούρτη).

- Τα δεδομένα (πελάτες, πλάνα, φωτογραφίες) **δεν** βρίσκονται σε αυτό το repository· είναι στο Supabase, προστατευμένα με Row Level Security.
- Το κλειδί `sb_publishable_…` στον κώδικα είναι δημόσιο από σχεδιασμό.
